# Library Management System

A command-line based Library Management System developed using Python. This project provides a simple and efficient way to manage library operations through a terminal interface.

## Features

- **Book Management:** Add, view, search, and delete books.
- **User Management:** Register users and manage user accounts.
- **Book Issuing:** Issue books to registered users.
- **Book Returns:** Return borrowed books and update availability.
- **Due Date Tracking:** Manage book issue and return dates.
- **Fine Management:** Calculate fines for overdue book returns.
- **Data Storage:** Store and manage library records using JSON files.

## Technologies Used

- Python
- JSON
- File Handling
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd Library-Management-System
   ```

3. Run the application:
   ```bash
   python main.py
   ```
